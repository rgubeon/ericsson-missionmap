# Mission Map — Ericsson at GITEX Global 2026

Self-contained presentation (single `index.html`, no external dependencies).

## Publish on GitHub Pages
1. Upload the contents of this folder to the root of a repository (or `/docs`).
2. Settings → Pages → Source: *Deploy from a branch* → `main` / root (or `/docs`).
3. Open `https://<user>.github.io/<repo>/`.

## Controls
- ← / → or click: navigate
- R: replay slide animations
- M: show/hide thumbnails
- Download PDF: print to PDF (one page per slide)
